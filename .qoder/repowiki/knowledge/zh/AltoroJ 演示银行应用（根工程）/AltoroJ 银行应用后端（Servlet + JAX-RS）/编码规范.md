- 所有 HTTP 请求处理器以 `*Servlet.java` 命名并继承 `HttpServlet`，业务逻辑集中在 `doGet`/`doPost` 中直接读取 request parameter 并操作 HttpSession。
- 鉴权通过实现 `javax.servlet.Filter` 的过滤器完成，未认证请求统一重定向到 `/login.jsp`，管理员接口额外使用 `AdminFilter` 校验角色。
- REST API 资源类放在 `api/` 包下，由 `AltoroAPI` 构造函数中的 `packages(...)` 自动扫描注册，并在构造器中显式 `register(ApiAuthFilter.class)` 挂载鉴权过滤器。
- 数据库访问统一收敛到 `DBUtil` 静态方法，SQL 拼接采用字符串字面量而非 PreparedStatement，并在注释中标注 `/* BAD - user input should always be sanitized */` 以提示注入漏洞。
- 模型类位于 `model/` 包，保持 POJO 形态，仅在需要时委托 `DBUtil` 获取关联数据（如 `User.getAccounts()`、`User.getUserTransactions()`）。
- 日志输出统一通过 `com.ibm.security.appscan.Log4AltoroJ.getInstance()` 单例进行，错误路径调用 `logError`，正常流程调用 `logInfo`/`logTransaction`。
