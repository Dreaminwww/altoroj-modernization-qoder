模块按经典三层划分：
- `servlet/`：传统 MVC 控制器，继承 `HttpServlet`，处理登录、转账、账户查看、反馈等页面请求，通过 `doGet/doPost` 直接操作 Session 并转发到 JSP。
- `api/`：基于 JAX-RS (Jersey) 的 REST 接口，由 `AltoroAPI` 作为 `ResourceConfig` 入口，`@ApplicationPath("api")` 注册所有资源类，并通过 `ApiAuthFilter` 做鉴权。
- `filter/`：三个 `javax.servlet.Filter`——`AuthFilter`（用户认证拦截）、`AdminFilter`（管理员权限拦截）、`ApiAuthFilter`（REST API 鉴权），统一在会话中检查 `User` 对象。
- `model/`：纯数据实体 `User`/`Account`/`Transaction`/`Feedback`，其中 `User` 持有 `Role` 枚举（User/Admin）并提供对 `DBUtil` 的便捷访问方法。
- `util/`：横切工具——`DBUtil` 封装 Derby JDBC 连接池与全部 SQL 操作（建表、CRUD、转账事务），`ServletUtil` 管理应用属性、日志文件与会话 Cookie，`OperationsUtil` 提供通用逻辑。
- `listener/StartupListener` 实现 `ServletContextListener`，在容器启动时初始化应用属性、日志、Derby 数据库及 REST API。
依赖方向单向：servlet/api → filter/model/util → DB；filter 仅依赖 util 与 model，不反向依赖 servlet。
