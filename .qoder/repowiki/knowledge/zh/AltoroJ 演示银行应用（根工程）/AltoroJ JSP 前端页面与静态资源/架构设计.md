本模块是 AltoroJ 的 Web 展示层，由 Servlet 2.5 容器（web.xml）驱动：
- 入口与路由：`WEB-INF/web.xml` 声明 `*.jsp` / `*.jspf` 由内置 jsp servlet 处理；业务动作通过显式 `<servlet>` + `<servlet-mapping>` 映射到 `com.ibm.security.appscan.altoromutual.servlet.*`（LoginServlet、TransferServlet、AccountViewServlet、CCApplyServlet、SubscribeServlet、FeedbackServlet、AdminServlet、AdminLoginServlet、SurveyServlet、RedirectServlet），以及一个 Jersey `ServletContainer` 挂载 `com.ibm.security.appscan.altoromutual.api.AltoroAPI` 作为 REST API。
- 安全边界：`AuthFilter` 拦截 `/bank/*`、`/admin/*`、`/account.jsp`，`AdminFilter` 拦截 `/adimn/*`（含拼写错误），统一在请求/转发/包含/错误路径上校验会话中的 `user` 属性。
- 页面组织：根目录为公共页面（`index.jsp`、`login.jsp`、`feedback.jsp`、`status_check.jsp`、`survey_questions.jsp` 等），使用 `header.jspf` / `footer.jspf` / `toc.jspf` 作为模板片段；`bank/` 存放网银功能页（main/balance/transfer/apply/stocks/transaction/queryxpath），`admin/` 存放管理员页（admin/feedbackReview/login），`util/` 放置 SWF 状态检查与 swfobject 脚本。
- 静态内容：`static/` 下按 personal/business/inside/jobs/pr 分目录的 .htm 文档，`images/` 提供站点图片，`pr/` 放 PDF/RTF 附件，`swagger/` 内嵌完整的 swagger-ui 前端用于调试后端 API。
- 依赖方向：JSP 仅依赖后端 Java 包 `com.ibm.security.appscan.altoromutual.model.*`、`ServletUtil` 以及 session 中预置的 `user` 对象，不直接访问数据库或业务逻辑。
