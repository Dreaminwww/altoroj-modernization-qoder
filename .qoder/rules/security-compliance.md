# 金融安全与合规规范
本项目是对银行系统 AltoroJ 的现代化改造，目标是修复安全漏洞、升级技术栈，不新增业务功能。

- 数据库：禁止用字符串拼接 SQL，必须使用 PreparedStatement 参数绑定；Statement 和 ResultSet 用 try-with-resources 自动关闭。
- 凭据：禁止在代码中写死账号、密码、密钥；密码不得明文存储，使用 BCrypt 加盐哈希。
- 个人资料：日志中不得输出密码、令牌、完整账号、身份证号、手机号；确需记录时脱敏，只保留后 4 位。遵循香港《个人资料（私隐）条例》。
- 权限：所有管理功能必须同时校验"已登录"和"管理员角色"。
- 金额：新代码中的金额使用 BigDecimal；转账必须校验金额大于 0、余额充足，并在同一个数据库事务中完成。
- 页面输出：显示到页面上的用户输入必须做 HTML 转义。
